# 🌸 Madhava — The Eternal Beloved

> *When confusion clouds the mind, guidance must come from within.
> This app brings the timeless voice of **Shri Krishna** to the modern seeker.*

**Madhava** is a spiritual AI companion inspired by the **Bhagavad Gita**, designed to guide users through doubt, fear, and decisions with calm, clarity, and dharma-centered wisdom.

It is not a chatbot.
It is a **digital charioteer**.

---

## 🪷 Vision

In the battlefield of life, every Arjuna needs a Krishna.

This project transforms ancient guidance into an interactive experience where users can:

* ask questions during confusion
* seek clarity in difficult decisions
* receive calm and truthful responses
* reconnect with purpose and responsibility

---

## ✨ Features

🌸 Krishna-style conversational guidance
🪷 Sanskrit shloka support when relevant
🎨 Customizable chat interface colors
🖼 Changeable background image
📜 Persistent chat history
⚙️ Elegant settings page
🔊 Background flute ambience support
🌙 Minimal spiritual UI design
📱 Optimized mobile experience

---

## 🧠 How It Works

The assistant responds as **Shri Krishna speaking to Arjuna**, following these principles:

* speaks calmly but truthfully
* corrects confusion directly
* encourages courage and action
* avoids flattery
* prioritizes dharma over comfort
* adapts language (English / Hindi / Hinglish)
* keeps responses concise and meaningful

## ⚙️ Installation

Clone repository:

```
git clone https://github.com/your-username/madhava-app.git
```

Navigate into project:

```
cd madhava-app
```

Install dependencies:

```
flutter pub get
```

Run application:

```
flutter run
```

---

## 🔐 API Integration

Uses **Gemini API** for response generation.

Add your key inside:

```
API.dart
```

Example:

```
static const String _apiKey = "YOUR_API_KEY";
```

## 📿 Philosophy Behind the Design

The interface follows three guiding principles:

**Silence** → minimal distractions
**Clarity** → direct responses
**Compassion** → supportive tone

Every design choice reflects stillness rather than stimulation.
